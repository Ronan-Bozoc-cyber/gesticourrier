V1.2 Novembre 25
-----------------
1) Ajout de statistiques en page d'accueil.
2) Gestion du passage d'une année à une autre
   - modification de la base de données par ajout du champ année
   - le champ année est autoalimenté par des TRIGGERS
Trigger                  Event   Table              Statement                     Timing   Created
update_annee_arrive      INSERT  courriers_arrive   SET NEW.annee = YEAR(NEW.date) BEFORE   2025-11-13 11:01:38.64
update_annee_arrive_on_update UPDATE courriers_arrive SET NEW.annee = YEAR(NEW.date) BEFORE 2025-11-13 11:01:59.20
update_annee_depart      INSERT  courriers_depart   SET NEW.annee = YEAR(NEW.date) BEFORE   2025-11-13 11:01:50.41
update_annee_depart_on_update UPDATE courriers_depart SET NEW.annee = YEAR(NEW.date) BEFORE 2025-11-13 11:02:07.94

   - renumérotation à 1 du Numéro d'ordre lors d'une nouvelle année
   - la référence à un enregistrement se fait par l'année / le numéro d'ordre
   - le listing des courriers est scindé en année

3) Lors de la création d'un enregistrement une fenêtre modale avec une barre de progression permet de patienter jusqu'à la fin du processus.
4) Lors de l'intégration des documents, le poids du fichier apparaît. S'il dépasse les 2 Mo un message en rouge apparaît.
5) La modification d'un courrier se fait par le bouton de modification qui ouvre une fenêtre modale demandant l'année et le numéro d'ordre.
6) L'association de courriers entrants aux courriers sortants (et réciproquement) est pleinement fonctionnelle.
7) Suppression du bouton de suppression pour la gestion des contacts, des catégories et des utilisateurs.
8) Le bouton pour envoyer un mail contenant les résultats de recherche a été enlevé.
9) Pour la recherche : sélection de l'année et colonne dans laquelle apparaît un courrier associé avec la coloration adaptée (numéro d'ordre et liens vers le document associé).

Pour l'installation :
* le fichier permettant de préciser les URL de base : partials/parametres.php
* la connexion à la base de données : partials/connexion.php

Pour le passage à la nouvelle version, la base de données a été modifiée :

ALTER TABLE courriers_arrive DROP INDEX num_ordre;
ALTER TABLE courriers_depart DROP INDEX num_ordre;

ALTER TABLE courriers_arrive ADD COLUMN annee INT;
ALTER TABLE courriers_depart ADD COLUMN annee INT;

UPDATE courriers_arrive SET annee = YEAR(date);
UPDATE courriers_depart SET annee = YEAR(date);

ALTER TABLE courriers_arrive ADD UNIQUE  (num_ordre,annee);
ALTER TABLE courriers_depart ADD UNIQUE  (num_ordre,annee);

CREATE TRIGGER update_annee_arrive BEFORE INSERT ON courriers_arrive FOR EACH ROW SET NEW.annee = YEAR(NEW.date);
CREATE TRIGGER update_annee_depart BEFORE INSERT ON courriers_depart FOR EACH ROW SET NEW.annee = YEAR(NEW.date);

CREATE TRIGGER update_annee_arrive_on_update BEFORE UPDATE ON courriers_arrive FOR EACH ROW SET NEW.annee = YEAR(NEW.date);
CREATE TRIGGER update_annee_depart_on_update BEFORE UPDATE ON courriers_depart FOR EACH ROW SET NEW.annee = YEAR(NEW.date);

SHOW TRIGGERS;
